# 01_行情頻寬現況與建議

這張投影片說明目前證券交易所行情線路的頻寬現況與改善方向。以六月二十五日尖峰時段、上午九點零五分為例,五個行情 IP 的流量分別是:第一 IP 約八 Mbps、第二 IP 約十二 Mbps,這兩者屬於即時訊息;第三 IP 約三 Mbps,屬於快照訊息;第四與第五 IP 都很小,分別只有零點三與零點四 Mbps。五個 IP 合計大約二十三點七 Mbps,再加上櫃買中心的 OTC 行情,總計約三十 Mbps。問題在於,如果同時接收兩條線路的行情資訊,流量就會超過五十 Mbps,超出目前線路的上限。針對頻寬不足,我們提出三項建議:第一,第一與第二 IP 是即時訊息、第三 IP 是快照訊息,資訊商請依自身線路頻寬與需求,擇一接收;第二,依業務需求分流接收,或是只接收一份行情資訊,以降低線路負載;第三,提升硬體線路頻寬,電作部已於去年十二月底發文,全市場都可以申請七十 M 或一百 M 的線路升速,詳細內容請參考投影片下方的連結。
